# Usage
- Upload this folder or `skill.zip` to Seedance/CapCut as a custom skill.
- Use the included images (`space needle_skill.jpg`, `Max_a_can_you_take_this_im_skill.jpg`) as visual anchors.
- Combine with the provided prompt template in `SKILL.md` for best results.
 
## Prompt Template
Seedance-ready prompt (recommended):
"Rearview mirror close-up inside a car on a dark winter evening, wet windshield, a yellow school bus faintly visible in the background, only the bus's red warning lights glowing through the glass, worn military dog tags hanging from the mirror and gently swaying, shallow depth of field, subtle camera motion, moody cinematic realism, intimate and restrained, realistic urban night scene. Use image references for composition and color grading."

Negative prompt:
- Avoid bright daylight, police vehicles in-frame, exaggerated neon, cartoonish textures, excessive lens flare.

Notes:
- This skill is intended to bias composition and color rather than force exact photoreal replication — combine with short test renders to dial in look.
- If Seedance/CapCut requires a single-file manifest, use `skill.md` as the YAML metadata.
